💻 ڈیولپرز کے لیے مفت API (Free API Guide)

اگر آپ اپنی ویب سائٹ، ایپ یا بوٹ (Bot) بنانا چاہتے ہیں، تو آپ QafiaSaz کی تیز ترین API بالکل مفت استعمال کر سکتے ہیں۔ ہماری API ایک لاکھ سے زائد الفاظ کا ڈیٹا ملی سیکنڈز میں فراہم کرتی ہے۔

1. ہم قافیہ اور وزن ایک ساتھ تلاش کریں (Rhyme & Meter):

GET /api/rhyme?suffix=ار&meter=2122

// Response: [{"id": 1, "word": "کردار", "meter": "2122", "source": "txt"}, ...]

2. صرف وزن سے الفاظ تلاش کریں (By Meter):

GET /api/meter?meter=1222

مکمل اور خودکار ڈاکومینٹیشن (Swagger UI) دیکھنے کے لیے اور لائیو ٹیسٹ کرنے کے لیے ہمارے API Docs (/docs) پیج پر وزٹ کریں۔
